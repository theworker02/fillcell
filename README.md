# fillcell

Fill structured JSON cell payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/fillcell/

## Install / run

```bash
git clone https://github.com/theworker02/fillcell.git
cd fillcell
node src/cli.js
node --test
```
